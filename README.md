## Project Overview

Student Life Management Services (SLMS) is a static website built to provide academic support services to university and college students. The website helps students manage their academics, time, and finances in one place by connecting them with experienced tutors across multiple disciplines.

The website aims to:

- Provide students with clear information about academic support services
- Showcase affordable pricing plans for different student budgets
- Motivate and encourage students through inspirational content
- Allow students to contact SLMS easily through an online form
- Build trust and credibility for the SLMS brand online

## Services Offered

- **Communication Technology** – Software Development, Database Management, Network Configuration
- **Finance and Accounting** – Financial Management, Business Accounting, Accounting Science
- **Commerce** – Digital Marketing, Supply Chain Management, Logistics
- **Law Studies** – Legal Inspector, Business Law, Compliance Officer
- **One-on-One Tutoring** – Study plans, Exam preparation, Session consultations

## How to Run

1. Download or clone the project folder
2. Open `index.html` in any modern web browser
3. Navigate between pages using the navigation links

No server or installation is required — this is a fully static website.
