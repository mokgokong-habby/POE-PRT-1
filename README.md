The website aims to:

- Provide students with clear information about academic support services
- Showcase affordable pricing plans for different student budgets
- Motivate and encourage students through inspirational content
- Allow students to contact SLMS easily through an online form
- Build trust and credibility for the SLMS brand online

---

## Website Pages

The website consists of the following five pages:

| Page | File Name | Description |
|---|---|---|
| Home | index.html | Main landing page with mission and overview |
| Services | service.html | Details of all academic support services |
| Pricing | enquiry.html | Pricing plans and payment policy |
| Motivation | about.html | Inspirational content and student tips |
| Contact | contact.html | Contact details and enquiry form |

---

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content markup |
| CSS3 | Styling, layout, and responsive design |
| JavaScript | Form validation and interactive features |
| Google Fonts | Web typography enhancement |
| Font Awesome | Icons for navigation and contact sections |
| Formspree | Contact form email submission handling |
